# Dan Zigmond

Data scientist, Zen teacher and priest. I use computational and machine learning methods to study ancient Buddhist texts, especially the Pāli Canon and the Chinese Taishō Canon, and I'm interested in how we can trust AI on questions no human can easily check.

Previously I led data science and engineering teams at Microsoft, Google, Facebook, Instagram, and Apple. More at [shmonk.com](https://shmonk.com).

## Pāli Canon

- [tipitaka](https://github.com/dangerzig/tipitaka): R package for computational analysis of the Pāli Canon ([on CRAN](https://cran.r-project.org/package=tipitaka))
- [tipitaka.critical](https://github.com/dangerzig/tipitaka.critical): lemmatized five-witness critical edition of the complete Pāli Canon, as an R package ([on CRAN](https://cran.r-project.org/package=tipitaka.critical))
- [pali-canon](https://github.com/dangerzig/pali-canon): the Python pipeline behind it: collation, lemmatization with the Digital Pāli Dictionary, and analysis tools
- [palifinder](https://github.com/dangerzig/palifinder): my fork of SuttaCentral's Pāli search engine, with contributions to stemming

## Chinese Buddhist Canon

- [taisho-canon](https://github.com/dangerzig/taisho-canon): detecting digest texts (*chaojing* 抄經) across the Taishō Canon
- [heart-sutra](https://github.com/dangerzig/heart-sutra): a multilingual critical edition of the Heart Sūtra (Chinese, Sanskrit, and Tibetan witnesses)

## Tools for working with AI

- [emacs-mcp](https://github.com/dangerzig/emacs-mcp): an MCP server connecting Claude Code to a running Emacs
